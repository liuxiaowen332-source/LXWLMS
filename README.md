## 2. 프로젝트 소개 / 项目简介
### 🇰🇷 한국어
본 프로젝트는 대학생들이 다양한 전공 및 교양 과목의 과제(Assignment)를 체계적으로 계획하고 관리할 수 있도록 돕는 웹 기반의 스마트 일정 관리 시스템입니다. 

생성형 AI와의 긴밀한 협업을 통해 현대적인 **Glassmorphism(유리 모핑/물유리)** UI 디자인과 반응형 레이아웃, 실시간 데이터 시각화(Chart.js 기반) 및 브라우저 로컬 저장소(LocalStorage)를 활용한 데이터 관리를 구현했습니다. 복잡한 과제들의 우선순위와 남은 시간을 한눈에 파악하여 마감일(Deadline)을 놓치지 않도록 직관적인 가이드를 제공합니다.

### 🇨🇳 中文
本项目是一个基于 Web 的智能课程作业与日程管理系统，旨在帮助大学生系统地规划和管理各类专业及公选课的课后作业（Assignment）。

通过与生成式 AI 深度协同开发，本项目实现了现代化的 **Glassmorphism（玻璃拟态）** UI 设计、自适应响应式布局、基于 Chart.js 的实时数据统计可视化图表以及基于 LocalStorage 的数据本地持久化。它可以让学生一目了然地掌握繁杂作业的优先级与截止时间倒计时，从而合理分配学习时间，避免遗漏截止日期。

## 3. 주요 기능 / 主要功能

### 📝 과제 관리 (作业增删改查)
* **과제 추가/편집 (添加与编辑作业)**: 과목명, 과제 제목, 마감일(시간 포함), 우선순위(상/중/하), 예상 소요 시간, 과제 상세 설명을 입력하여 새로운 과제를 등록하고 수정할 수 있습니다.
* **과제 상태 변경 (标记完成状态)**: 체크박스를 클릭하여 상태를 '진행 중'에서 '완료'로 쉽게 전환할 수 있습니다. 완료 시 텍스트 취소선과 투명도 처리가 적용됩니다.
* **하위 작업 분할 (子任务拆解 Subtasks)**: 하나의 과제를 여러 세부 단계로 나누어 개별 관리할 수 있으며, 하위 작업 완료율이 게이지 바에 실시간 반영됩니다.
* **과제 삭제 (删除作业)**: 마우스 호버(Hover) 시 나타나는 삭제 버튼을 통해 부드러운 애니메이션과 함께 과제를 목록에서 영구 제거합니다.
* **데이터 영구 보존 (数据持久化)**: 모든 데이터는 브라우저의 `LocalStorage`에 실시간으로 동기화되어 페이지를 새로고침하거나 브라우저를 재시작해도 유지됩니다.

### 📊 실시간 자동 통계 및 대시보드 (数据自动统计)
* **수치 대시보드 (数值统计看板)**: 전체 과제 개수, 미완료 과제 개수, 완료율(%)이 카운팅과 게이지 바 형태로 상단에 실시간 반영됩니다.
* **학습 시간 예산 (时间预算)**: 총 예상 소요 시간(Estimated Hours)과 실제 완료된 과제의 총 소요 시간을 합산하여 학습 투입 시간을 실시간으로 계산합니다.
* **그래프 시각화 (图表可视化)**: **Chart.js**를 활용하여 미완료 과제의 우선순위 분포를 원형 차트(Doughnut Chart)로, 과목별 과제 분포를 막대 차트(Bar Chart)로 동적으로 그려줍니다.
* **마감일 긴급성 분류 (截止日期倒计时)**: 현재 시각 기준으로 마감 기한이 초과된 과제(빨강), 24시간 이내(주황), 3일 이내(보라), 기한이 넉넉한 과제(파랑)를 뱃지 및 문구로 실시간 경고 및 표시합니다.

### 🔍 필터 및 정렬 (过滤与排序)
* **다중 필터 (多重过滤)**: 과목별, 과제 진행 상태별(전체/미완료/완료), 우선순위별로 원하는 과제만 필터링하여 볼 수 있습니다.
* **정렬 기능 (排序)**: 마감일이 가장 임박한 순서(Default), 마감일이 늦은 순서, 우선순위가 높은 순서, 예상 소요 시간이 많은 순서로 과제 목록을 정렬합니다.

### 💾 데이터 백업 및 복원 (数据导入与导出)
* JSON 형식으로 현재 관리 중인 모든 과제 데이터를 파일로 내보내기(Export)하거나, 기존에 저장해 둔 JSON 백업 파일을 불러와(Import) 손쉽게 복구할 수 있습니다.

## 4. 사용한 AI 도구 / 使用的 AI 工具
- **AI Tool**: **Google Gemini (via Antigravity AI Coding Assistant)**
- **협업 내용 / 协作内容**:
  - **기획 및 아키텍처 (规划与架构)**: 과제 관리자 앱의 핵심 기능 요구사항 정의 및 파일 디렉토리 아키텍처 설계.
  - **UI/UX 디자인 (UI/UX 视觉设计)**: HSL 기반 다크/라이트 모드 테마, CSS Glassmorphism 효과, 반응형 CSS Grid 그리드 정의.
  - **코드 구현 (核心代码编写)**: LocalStorage 연동 모듈, 마감일 자동 계산 헬퍼 함수, Chart.js와의 데이터 동적 갱신 바인딩 코드 협동 개발.
  - **디버깅 및 최적화 (调试与优化)**: 모바일 뷰포트 크기 변화에 따른 Chart.js 컨테이너 반응형 오동작 해결 및 애니메이션 트랜지션 성능 디버깅.

## 6. 실행 방법 / 运行方法

### 🇰🇷 한국어
본 프로젝트는 추가적인 서버 구축이나 의존성 패키지 설치(npm install) 없이 **웹 브라우저가 설치된 모든 환경에서 즉시 실행 가능**합니다.

* **방법 A (가장 간단)**: 프로젝트 폴더 내 `index.html` 파일을 더블클릭하여 사용하는 웹 브라우저(Chrome, Safari, Edge 등)에서 바로 엽니다.
* **방법 B (권장)**: VS Code에서 폴더를 열고 **Live Server** 익스텐션을 설치한 후, 우측 하단의 `Go Live` 버튼을 클릭하여 로컬 호스트 주소(`http://127.0.0.1:5500/index.html`)로 접속합니다.

### 🇨🇳 中文
本项目无需配置 Node.js 环境或安装任何 npm 包，**下载解压即可在任意主流浏览器中完美运行**：

* **方法 A (直接双击)**：双击项目文件夹中的 `index.html`，即可直接在您的默认浏览器中预览、体验全部功能。
* **方法 B (推荐使用 Live Server)**：在 VS Code 中打开本文件夹，安装并运行 **Live Server** 插件，点击编辑器右下角的 `Go Live`，即可通过本地服务器 `http://127.0.0.1:5500/index.html` 访问项目。
